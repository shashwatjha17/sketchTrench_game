# SketchTrench

SketchTrench is a modern real-time multiplayer drawing and guessing game inspired by Skribbl.io, built with a Java-first technology stack. Players create or join game rooms, take turns sketching randomly assigned words, and compete to guess drawings as quickly as possible to earn points and climb the global leaderboard.
